# 1.1.0
**UI**
- Adjusted the width of the vanilla tickbox element area.

**CONTROLLER**
- Custom tickboxes now work with gamepad navigation.

**FIXES**
- Fixed tickbox sizes to match vanilla.
- Fixed custom filters resetting the selected category when "Show All Recipes" was active with a hidden category selected.
- Fixed the vanilla "Show All Versions" tickbox missing from gamepad navigation in the build menu.

**LOCALIZATION**
- Added localization for crafting UI elements: fluid amount suffix, crafting time, quantity label, and force-craft button. 

**TECHNICAL**
- The changelog format was updated to Markdown.
- B42.13 - B42.19 support has been discontinued.

# 1.0.2
- Experience gain for recipes is now displayed again.

# 1.0.1
- All localization files migrated to the new format.
- Experience gain display for recipes is no longer supported.

# 1.0.0
- The mod's logic has been completely rewritten (reduced from 11 files to 5).
- Hovering over the crafting output now displays full item information (tooltip).
- The displayed XP gain now accounts for all possible multipliers (Traits, Skill Books, Sandbox settings).
- The visual separation between tools and items has been removed to save screen space.
- The selected category and recipe are now remembered (state persistence).
- Certain recipe categories added by other mods are now merged.
- Added tooltips when hovering over filter options.
- Removed the dependency on the Starlit library.
